# LibrePrint 0.1.0

LibrePrint sets up and manages printers on Ubuntu and Debian without the manufacturer's software.
It detects your printer, creates the print queue, and gives you an app for printing, scanning, ink
levels and troubleshooting.

## Supported printers

Any printer that supports driverless printing (IPP Everywhere / AirPrint), over Wi-Fi, network or
USB. That covers most models sold in the last decade from all major brands. Older HP models are
supported through HPLIP.

## Features

- Setup in one command, with automatic setup when a printer is connected
- Ink levels with low-ink warnings
- Print queue with cancel controls
- Print options: copies, two-sided, colour, quality and page ranges; page order follows the
  printer's output tray so the stack comes out in reading order
- Multi-page scanning to PDF, PNG or JPEG for eSCL (AirScan) scanners
- Diagnostics with suggested fixes (`libreprint doctor`)

## Install

```sh
curl -fsSL https://YOUR-USERNAME.github.io/libreprint/install.sh | sh
```

This adds the signed APT repository, so updates arrive through `sudo apt upgrade`. You can also
install `libreprint_all.deb` from the assets below.

The app needs Ubuntu 24.04+ or Debian 13. The command-line tool also runs on Ubuntu 22.04 and
Debian 12.

## Notes

LibrePrint is not a driver. It configures the existing Linux printing stack (CUPS, IPP Everywhere,
ipp-usb, SANE, HPLIP). This release was tested on an HP ENVY 6000 series. Reports for other models
are welcome in [docs/HARDWARE.md](https://github.com/YOUR-USERNAME/libreprint/blob/main/docs/HARDWARE.md).

# LibrePrint 0.1.2

## New

- **Print several documents at once.** Add as many files as you like with **Add files…** (hold Ctrl
  in the file window to pick several) or drag them onto the Print page. They are printed so the
  stack comes out in the order of the list, and the options apply to every document.
- **Remove button** on every document, so you can change your mind without choosing the file again.
  It only takes the file off the list, never off your computer.

## Improved

- **No more waiting for Office files.** Adding one is now instant, and it is converted in the
  background. You can press Print right away: it goes to the printer as soon as it is ready. The
  conversion itself still takes as long as LibreOffice needs, and Preview becomes available when it
  finishes.
- **The Print page clears as soon as you press Print**, and the options go back to their defaults.
  If a document cannot be printed, it comes back to the list with your options so you can try again.
- Closing the window while documents are still being prepared no longer loses them: LibrePrint
  finishes sending them first.

## Install

```sh
curl -fsSL https://juujbyg.github.io/libreprint/install.sh | sh
```

If you already added the APT repository, `sudo apt update && sudo apt upgrade` gets this version.

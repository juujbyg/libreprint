# LibrePrint 0.1.1

## Fixes

- Files dragged from the Recent view of GNOME Files onto the Print page are now accepted. They used
  to be rejected with "That is not a file that can be printed".

## Install

```sh
curl -fsSL https://juujbyg.github.io/libreprint/install.sh | sh
```

If you already added the APT repository, `sudo apt update && sudo apt upgrade` gets this version.

# hpeasy v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Debian/Ubuntu package (`hpeasy`) that auto-detects any HP printer/MFP (USB or network), picks driverless / HPLIP / HPLIP+plugin, creates the CUPS queue, configures scanning, and diagnoses common failures — via a CLI and a hotplug/network auto mode.

**Architecture:** Pure-stdlib Python package in `src/hpeasy/` orchestrating system tools (`lpinfo`, `lpadmin`, `avahi-browse`, `ipptool`, `hp-*`, `scanimage`, `apt-get`). Every external call/file access goes through an injectable `Runner`; tests use `FakeRunner` with real recorded outputs. A pure `decide()` maps a `Device` to a `Plan`; `setup.py` executes plans; `doctor.py` diagnoses. udev + systemd units invoke `hpeasy auto` / `hpeasy watch`. The `.deb` is built with a plain `dpkg-deb` script (arch `all`).

**Tech Stack:** Python ≥3.10 stdlib only (runtime); pytest + ruff (dev); dpkg-deb; GitHub Actions with ubuntu/debian containers; CUPS `ippeveprinter` for integration tests.

**Spec:** `docs/superpowers/specs/2026-10-28-hpeasy-design.md`

## Global Constraints

- Python ≥ 3.10, **standard library only** at runtime. No `match` on 3.11+ features (no `tomllib`, no `ExceptionGroup`, no `typing.Self`).
- Targets: Ubuntu 22.04 / 24.04 / 26.04, Debian 12 / 13; amd64 + arm64 (package is arch `all`).
- License GPL-2.0-or-later. Every source file starts with `# SPDX-License-Identifier: GPL-2.0-or-later`.
- Never redistribute the HP plugin; only install via `hp-plugin` after explicit consent (or `accept_hp_plugin_license = true` in config).
- Never modify or delete a CUPS queue hpeasy did not create, unless `--force`.
- All user-facing messages in English. README notes "not affiliated with HP Inc."
- Exit codes: 0 ok · 1 error · 2 usage · 3 needs root · 4 no HP device found · 5 user action required (plugin license).
- Paths: state `/var/lib/hpeasy/state.json`, config `/etc/hpeasy/hpeasy.conf`, lock `/run/hpeasy.lock`, HPLIP db `/usr/share/hplip/data/models/models.dat`, HPLIP state `/var/lib/hp/hplip.state`.
- Every subprocess runs with `LC_ALL=C` and `DEBIAN_FRONTEND=noninteractive` added to the environment.
- Tests never touch the real filesystem outside `tmp_path` and never run real system commands except in `tests/test_runner.py` (which runs `sys.executable`).
- Run tests with `python -m pytest -q`; lint with `ruff check src tests`.

## Review Focus

1. **Minimal environments** (containers without `systemctl`, `avahi-browse`, `hplip`, `scanimage`): discovery and every doctor check must degrade to "skipped/unknown", never a traceback. → tests in Task 3 (`test_discover_without_avahi`) and Task 8 (`test_doctor_without_systemctl`).
2. **Non-English locale**: parsers assume English output → `Runner` forces `LC_ALL=C`. → Task 1 `test_runner_forces_c_locale`.
3. **One printer, many sightings** (usb:// + hp:/usb/ from lpinfo, ipp-usb on `lo`, IPv4 + IPv6 avahi lines, `_ipp` + `_uscan` records): must merge into one `Device` and one queue. → Task 3 `test_merge_usb_and_ippusb`, `test_merge_ipv4_ipv6_and_uscan`.
4. **Avahi escaping / odd TXT** (`\032`, `\091`, values with spaces, `ty=HP OfficeJet Pro 9010 series [ABC123]`): model name must be clean. → Task 3 `test_avahi_unescape_and_model`.
5. **Re-runs and races** (setup twice; USB hotplug and netwatch firing together; queue created by CUPS/user with a dnssd URI carrying `uuid=`): no duplicate queue. → Task 4 `test_find_existing_by_uuid_in_dnssd_uri`, Task 7 `test_setup_is_idempotent`.

**Interfaces — Produces:**
```python
# runner.py
@dataclass(frozen=True)
class Result:
    code: int; out: str = ""; err: str = ""
    @property
    def ok(self) -> bool  # code == 0

class Runner:
    def run(self, argv: list[str], *, input: str | None = None, timeout: float = 60) -> Result
        # missing binary -> Result(127, "", f"{argv[0]}: command not found"); timeout -> Result(124, "", "timeout")
    def run_interactive(self, argv: list[str]) -> int   # inherits stdio; returns exit code
    def stream(self, argv: list[str]) -> Iterator[str]  # yields stdout lines until process exits
    def which(self, name: str) -> str | None
    def read_file(self, path: str) -> str | None        # None if missing/unreadable
    def write_file(self, path: str, content: str) -> None  # creates parent dirs
    def exists(self, path: str) -> bool
    def listdir(self, path: str) -> list[str]           # [] if missing
    def sleep(self, seconds: float) -> None

class FakeRunner(Runner):
    def __init__(self, files: dict[str, str] | None = None, binaries: set[str] | None = None)
        # binaries=None means "every binary exists"
    def on(self, *argv: str, out: str = "", err: str = "", code: int = 0) -> "FakeRunner"  # chainable
    calls: list[list[str]]          # every run/run_interactive argv, in order
    interactive_calls: list[list[str]]
    inputs: list[str | None]        # input= passed to each run()
    files: dict[str, str]           # write_file updates this
    stream_lines: dict[tuple[str, ...], list[str]]  # set directly by tests
    slept: list[float]
```
Matching rule for `FakeRunner.run`: exact `tuple(argv)` registered → that result; else the registered prefix with the most elements that `argv` starts with; else `Result(0)`. If `binaries` is a set and `argv[0]` not in it → `Result(127, "", ...)`. `which(name)` → `f"/usr/bin/{name}"` iff binary exists. `sleep` records and returns immediately.

### Task 3: Discovery

**Files:** Create `src/hpeasy/discovery.py`, fixtures `tests/fixtures/lpinfo_usb.txt`, `tests/fixtures/avahi.txt`, `tests/fixtures/ipptool.txt`; Test `tests/test_discovery.py`

**Interfaces — Consumes:** `Runner`, `Device`, `hplipdb.normalize_model`. **Produces:**
```python
def parse_lpinfo(out: str) -> list[Device]
def parse_avahi(out: str) -> list[Device]
def parse_ipptool(out: str, uri: str) -> Device | None
def merge(devices: list[Device]) -> list[Device]
def discover(runner: Runner) -> list[Device]      # lpinfo -l -v (timeout 60) + avahi-browse -a -r -p -t (timeout 15), merged
def probe_uri(runner: Runner, uri: str) -> Device | None
    # ipp/ipps: ipptool -T 10 -tv URI get-printer-attributes.test -> parse_ipptool
    # hp:/usb/<Model>?serial=X or hp:/net/<Model>?ip=A: Device built from URI (model = path tail with "_"→" ")
    # other schemes or failure: None
```
Rules:
- HP filter: `MFG:` in device-id is `HP`/`Hewlett-Packard` (case-insensitive), or make-and-model starts with HP/Hewlett-Packard, or URI scheme `hp`. Avahi: TXT `usb_MFG` is HP/Hewlett-Packard, or `ty`/`product` starts with `HP`. Non-HP entries dropped.
- lpinfo: `usb://` and `hp:/usb/` → connection `usb`, `serial` from `serial=` query; `ipp_everywhere = True` if device-id `CMD:` tokens include `URF` or start with `PWG`. URIs `implicitclass://`, `cups-brf:`, and `dnssd://` are ignored (avahi covers network).
- Avahi line format (only lines starting `=`): `=;iface;proto;name;type;domain;host;address;port;"k=v" "k=v"...`. Unescape `\DDD` (decimal) in name. Types used: `_ipp._tcp`/`_ipps._tcp` → uri `ipp[s]://{address}:{port}/{rp or "ipp/print"}` (IPv6 address in brackets), `ipp_everywhere` if `pdl` contains `image/pwg-raster` or `image/urf`; `_uscan._tcp` → `escl=True`; `_pdl-datastream._tcp` → no uri, network device with ip. `iface == "lo"` → connection `usb` (ipp-usb), uri host `localhost`. `uuid` from TXT `UUID` lowercased. Model: TXT `usb_MDL` if present, else `ty` with HP prefix removed and any trailing ` [...]` removed.
- `merge`: network devices merge when same `uuid`, or (no uuid on one side) same `ip`; usb devices merge when same `serial`, or same `normalize_model(model)` and at least one side has no serial. Merged: union of uris (order: first-seen, no dups), OR of flags, first non-None of serial/uuid/ip; prefer IPv4 `ip`.

### Task 4: Queues

**Files:** Create `src/hpeasy/queues.py`, fixture `tests/fixtures/lpinfo_m.txt`; Test `tests/test_queues.py`

**Interfaces — Consumes:** `Device`, `normalize_model`. **Produces:**
```python
@dataclass(frozen=True)
class Queue: name: str; uri: str
def parse_lpstat_v(out: str) -> list[Queue]          # lines "device for NAME: URI"
def queue_name(model: str, taken: set[str]) -> str
def find_existing(device: Device, queues: list[Queue]) -> Queue | None
def lpadmin_argv(name: str, uri: str, ppd: str) -> list[str]
def find_hpcups_ppd(lpinfo_m_out: str, model: str) -> str | None
def disabled_queues(lpstat_p_out: str) -> list[str]   # "printer NAME disabled since ..." / "printer NAME is stopped" not needed: only "disabled"
```
- `queue_name`: `"HP_" + re.sub(r"[^A-Za-z0-9]+", "_", model).strip("_")`, truncated to 100 chars; if taken append `_2`, `_3`, …
- `find_existing`: match if `queue.uri` in `device.uris`; or device.serial and `serial=<serial>` (case-insensitive) in queue.uri; or device.uuid and `uuid=<uuid>` (case-insensitive) in queue.uri; or device.ip and `ip=<ip>` or `//<ip>:` in queue.uri.
- `lpadmin_argv` → `["lpadmin", "-p", name, "-E", "-v", uri, "-m", ppd, "-o", "printer-is-shared=false"]`.
- `find_hpcups_ppd`: each line `<ppd-name> <description>`; candidates whose description, normalized, contains `normalize_model(model)` as a whole `_`-delimited token sequence; prefer names starting `drv:///hpcups.drv/`, then `hplip:`, then `lsb/usr/HP/`; else None. Never pick `hpijs`, `foo2`, or `postscript-hp:`-unrelated models.

# Tested hardware

Models reported to work (or not) with hpeasy. Please add a row with a pull request, or mention
your result in an issue.

How to fill in a row:

- **Model**: as printed on the device, for example `HP OfficeJet Pro 9010`.
- **Connection**: `USB` or `Network`.
- **Method**: the METHOD column of `hpeasy list` (`driverless`, `hplip`, `hplip-plugin`,
  `unsupported`).
- **Distro**: for example `Ubuntu 24.04`.
- **hpeasy version**: output of `hpeasy --version`.
- **Reporter**: your GitHub handle.
